Advance the ENDO TTP model (zone 2) from the curated CellML ENDO initial state, with \(G_\mathrm{to}=0.073\), for 600 ms using \(\Delta t=0.005\,\mathrm{ms}\).

The seven main states use Forward Euler and the twelve gates use Rush–Larsen. The test applies \(I_\mathrm{stim}=-52\,\mathrm{pA/pF}\) for \(10\leq t<11\,\mathrm{ms}\), sets \(K_\mathrm{sac}=0\), and uses no pre-pacing.
