7/**
8 * @file Matrix.h
9 * @brief Fixed-size matrix types for FE computations, backed by Eigen.
10 *
11 * The FE library standardizes on Eigen for linear algebra. These aliases give
12 * element-level code a stable vocabulary type without re-exporting all of
13 * Eigen. Storage is Eigen's default (column-major); element access through
14 * operator()(row, col) is unchanged. Note that, unlike the previous in-house
15 * implementation, Eigen types are NOT zero-initialized by default
16 * construction; use Matrix::Zero() where a zeroed value is required.
17 */
18
