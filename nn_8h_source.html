43 /**
44 * @brief Return the area-weighted surface normal at a given element and Gauss
45 * point.
46 *
47 * Returns the outward normal at element 'e', Gauss point 'g' of face 'lFa',
48 * weighted by the surface Jacobian: Jac = norm(n) is the Jacobian of the
49 * mapping from the parent surface element to the reference/old/new
50 * configuration.
51 *
52 * For simulations involving structural displacement, this function allows
53 * computing the normal vector in any of the following configurations:
54 * - reference configuration (the mesh is not displaced);
55 * - current configuration (the mesh is displaced by the current displacement
56 * field);
57 * - old configuration (the mesh is displaced by the displacement field from
58 * previous time step).
59 *
60 * @todo[michelebucelli] This could be renamed to outward_normal, to match the
61 * function below.
62 *
63 * @param[in] com_mod The common module.
64 * @param[in] lFa The boundary face for which the normal vector is computed.
65 * @param[in] e The face-local index of the element for which the normal
66 * vector is computed.
67 * @param[in] g The Gauss point index for which the normal vector is computed.
68 * @param[in] Nx The shape function derivatives at the Gauss point. Its shape
69 * (insd x eNoNb) determines the surface's intrinsic dimension and the
70 * number of nodes per face element.
71 * @param[in] solutions The solution states that the displacement fields are
72 * extracted from.
73 * @param[in] cfg The configuration in which the normal vector is computed
74 * (reference, old, current or intermediate).
75 * @param[in] displacement_index The index of the displacement field in the
76 * solution arrays. This should correspond to the start index of the
77 * equation that solves for the displacement.
78 *
79 * @return The area-weighted outward normal vector.
80 */
81 Vector<double> gnnb(const ComMod &com_mod, const faceType &lFa, const int e,
82 const int g, const Array<double> &Nx,
83 const SolutionStates &solutions,
84 consts::MechanicalConfigurationType cfg,
85 const unsigned int displacement_index);

87 /**
88 * @brief Return the area-weighted surface normal at a given element and Gauss
89 * point.
90 *
91 * Returns the outward normal at element 'e', Gauss point 'g' of face 'lFa',
92 * weighted by the surface Jacobian: Jac = norm(n) is the Jacobian of the
93 * mapping from the parent surface element to the mesh.
94 *
95 * This is the overload to use in the general case. The other overload adds
96 * the ability to compute the normal in a displaced configuration, which is

98 *
99 * @todo[michelebucelli] This could be renamed to outward_normal, to match the
100 * function below.
101 *
102 * @param[in] com_mod The common module.
103 * @param[in] lFa The boundary face for which the normal vector is computed.
104 * @param[in] e The face-local index of the element for which the normal
105 * vector is computed.
106 * @param[in] g The Gauss point index for which the normal vector is computed.
107 * @param[in] Nx The shape function derivatives at the Gauss point.
108 * @param[in] solutions The solution states that the displacement fields are
109 * extracted from.
110 *
111 * @return The area-weighted outward normal vector.
112 */
113 Vector<double> gnnb(const ComMod &com_mod, const faceType &lFa, const int e,
114 const int g, const Array<double> &Nx,
115 const SolutionStates &solutions);

117 /**
118 * @brief Differentiate the cross product of the tangent vectors of a
119 * surface element at a Gauss point with respect to the positions of the
120 * element nodes.
121 *
122 * Tangent vector 'k' is the derivative of the position with respect to
123 * parametric coordinate 'k': the sum over the element nodes of Nx(k,a) times
124 * the position of node 'a'. The cross product is the one that utils::cross()
125 * returns, an area-weighted normal of the element.
126 *
127 * @param[in] tangents The tangent vectors at the Gauss point, one per column
128 * (nsd x insd).
129 * @param[in] Nx The shape function derivatives at the Gauss point
130 * (insd x eNoNb).
131 *
132 * @return The derivative (nsd x nsd x eNoNb): entry (j,i,a) is the derivative
133 * of component 'j' of the cross product with respect to coordinate 'i' of
134 * node 'a' of the element.
135 */
136 Array3<double> derivative_of_tangents_cross_product_wrt_position(
137 const Array<double> &tangents, const Array<double> &Nx);

139 /**
140 * @brief Differentiate the area-weighted outward normal of a face element at
141 * a Gauss point with respect to the positions of the element nodes.
142 *
143 * The normal is the one that gnnb() returns.
144 *
145 * Not available for the faces of shell meshes.
146 *
147 * @param[in] com_mod The common module.
148 * @param[in] lFa The boundary face.
149 * @param[in] e The face-local index of the element.
150 * @param[in] Nx The shape function derivatives at the Gauss point. Its shape
151 * (insd x eNoNb) determines the surface's intrinsic dimension and the
152 * number of nodes per face element.
153 * @param[in] solutions The solution states that the displacement fields are
154 * extracted from.
155 * @param[in] cfg The configuration in which the normal is computed
156 * (reference, old, current or intermediate).
157 * @param[in] displacement_index The index of the displacement field in the
158 * solution arrays. This should correspond to the start index of the
159 * equation that solves for the displacement.
160 *
161 * @return The derivative (nsd x nsd x eNoNb): entry (j,i,a) is the derivative
162 * of component 'j' of the normal with respect to coordinate 'i' of node
163 * 'a' of the face element.
164 */
