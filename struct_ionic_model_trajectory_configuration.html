Detailed Description

Configure one standalone trusted-reference IonicModel trajectory.

The configuration selects the public integration inputs and maps every model state to a column in the external reference CSV.

◆ state_reference_columns

std::vector<std::string> IonicModelTrajectoryConfiguration::state_reference_columns

CSV column name for every model state.

Entries correspond in order to X[0] through X[nX-1], followed by Xg[0] through Xg[nG-1]. Each entry names the CSV column containing the reference value for that state; the column name need not match the model state name. Every model state requires an entry, but the physical CSV column order may differ from this mapping order.
