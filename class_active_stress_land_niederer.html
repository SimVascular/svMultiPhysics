Detailed Description

Land-Niederer active stress model.

This class implements the phenomenological Land-Niederer active stress model [1], which represents the cross-bridge cycling and calcium-troponin binding kinetics in a single set of ODEs. The cross-bridges are modeled as a three-state system, with transitions between unbound (U), pre-power stroke (W), and post-power stroke (S) states. The blocked state (B) represents the tropomyosin blocking the actin binding sites, and the unblocked state (U) repesents the availability of these sites for cross-bridge binding. The unblocking of the tropomyosin is regulated by the calcium-troponin binding state (CaTRPN) and the fiber stretch. The distortion of the cross-bridges are also represented for the pre-power stroke and post-power stroke states. The active tension is computed as a function of the cross-bridge states and their distortions, scaled by a reference tension Tref. This is given as

\[ \Tact = L(\bar\lambda) \frac{Tref}{r_s} \left[ (1 + \zeta_S) X_S + \zeta_W X_W \right]\;, \]

with \(\bar\lambda=\min(1.2,\fiberstretch)\) and \(L(x)=\max(0,1+\beta_0(x+\min(0.87,x)-1.87))\), implemented by length_dependence_factor. \(X_S\) and \(X_W\) are the fractions of cross-bridges in the post-power stroke and pre-power stroke states, respectively. \(\zeta_S\) and \(\zeta_W\) are the distortions, and \(r_s\) is the steady-state duty ratio of the cross-bridges.

Calcium is expected in uM, after the scaling by Calcium_scaling_factor set in the <Active_stress> XML element (see Preprocessing of model inputs). Since electrophysiology models usually provide calcium in mM, inputs coupled to one need Calcium_scaling_factor set to 1000; it defaults to 1.0, and a warning is printed if it is not given. Setting Disable_force_strain_rate_feedback in the same element removes the fiber stretch rate term from the \(\zeta_W\) and \(\zeta_S\) distortion ODEs.

References:

  1. Land, Niederer (2017)
