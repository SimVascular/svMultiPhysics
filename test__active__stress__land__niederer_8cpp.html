Run a standalone ActiveStressLandNiederer twitch for 600 updates with \(\Delta t=1\,\mathrm{ms}\), the prescribed calcium and fiber-stretch trajectories, and the multiscale Land 2017 calibration configured below (svMP's model defaults).

The trusted reference is generated by driving the original MATLAB Land.m implementation (adapted from https://www.cemrg.co.uk/models) through the MATLAB engine with a manual Forward-Euler integrator that mirrors ActiveStressODE's update rule; it is not generated by svMultiPhysics. See this repo to access the reference solution generator and model. See ActiveStressLandNiederer for the model equations and state ordering: states 0-5 are the Land 2017 ODE states (XB, XW, CaTRPN, XS, ZETAW, ZETAS). The Frank-Starling length-dependence factor is not a state; it is evaluated from the fiber stretch when computing the active tension.
