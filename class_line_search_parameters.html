Detailed Description

Parameters of the line search shortening the increments of the nonlinear iterations of an equation.

The line search is enabled by the presence of the XML element and disabled by its absence.

XML element:

<Line_search>
<Minimum_decrease> 1.0e-4 </Minimum_decrease>
<Step_reduction_factor> 0.5 </Step_reduction_factor>
<Minimum_step_length> 0.015625 </Minimum_step_length>
<Verbose> false </Verbose>
</Line_search>
