Detailed Description

Parameters of the adaptive time step of a simulation.

The time step is adapted between steps when the XML element is present and fixed when it is absent. Within it, Maximum_time_step has to be given; Minimum_time_step and Maximum_growth_factor are optional.

XML element:

<Adaptive_time_step>
<Maximum_time_step> 100.0 </Maximum_time_step>
<Minimum_time_step> 1.0e-4 </Minimum_time_step>
<Maximum_growth_factor> 10.0 </Maximum_growth_factor>
</Adaptive_time_step>
