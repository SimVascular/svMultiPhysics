Detailed Description

Land-Niederer active-stress reference

The committed reference trajectory was produced with KB Ko's generate_ref_solution using the Land-Niederer human ventricular cardiomyocyte parameter set for multiscale simulations. It was not generated by svMultiPhysics.

The reference uses 600 outer updates with dt=1 ms. At the start of each update, calcium follows the normalized double-exponential transient prescribed by ActiveStressTrajectoryTest: baseline 1e-4 mM, peak 9e-4 mM, rise and decay constants 20 ms and 50 ms, and onset 10 ms. Sarcomere length follows the same raised-cosine trajectory, shortening from 2.2 um at 30 ms to 2.134 um at 150 ms and recovering to 2.2 um at 350 ms. Its rate is the forward difference [SL(t+dt)-SL(t)]/dt.

For each update, generate_unit_test_solution.py calls the MATLAB Land right-hand side with time in milliseconds, calcium in micromolar, dimensionless fiber stretch SL/2.2, and stretch rate [SL(t+dt)-SL(t)]/(2.2*dt) in 1/ms. The Python wrapper advances the six active states with Forward Euler. Active tension is stored in kPa (Tref=120 kPa, matching the model defaults), without the conversion to MPa used for slab validation.

The committed CSV stores step,Ta,s0,...,s5 at update indices 0,10,30,60,99,149,199,299,349,449,599, where index N is the result of the update starting at t=N ms. No ready-to-run generator is included because reproducing the data depends on installation of MATLAB. The trusted data remain in tests/unitTests/reference_data/active_stress_land_niederer_twitch.csv.
