# Regazzoni active-stress reference

The committed reference trajectory was produced with Francesco Regazzoni's
MIT-licensed
[`cardiac-activation`](https://github.com/FrancescoRegazzoni/cardiac-activation)
implementation at commit
`26f05df28891df7b3c69f16bb136cdced6b63c4d`, using the RDQ20-MF human
body-temperature parameter set. It was not generated by svMultiPhysics.

The pinned source leaves six structural-zero entries of the cross-bridge
matrix `XB_A` uninitialized. The reference run inserted `XB_A.setZero()`
before the populated entries were assigned, matching the zero-initialized
matrix in svMultiPhysics.

The reference uses 600 outer updates with `dt=1 ms`. At the start of each
update, calcium follows the normalized double-exponential transient prescribed
by `ActiveStressTrajectoryTest`: baseline `1e-4 mM`, peak `9e-4 mM`, rise and
decay constants `20 ms` and `50 ms`, and onset `10 ms`. Sarcomere length follows
the same raised-cosine trajectory, shortening from `2.2 um` at `30 ms` to
`2.134 um` at `150 ms` and recovering to `2.2 um` at `350 ms`. Its rate is the
forward difference `[SL(t+dt)-SL(t)]/dt`.

For each update, the authors' `solve_time_step` receives time in seconds,
calcium in micromolar, sarcomere length in micrometers, and its rate in
micrometers per second. The authors' code advances regulatory-unit states with
Forward-Euler substeps and cross-bridge moments with implicit Euler. Active
tension is divided by 1000 to convert kPa to MPa.

The state starts with `s0=1` and all other entries zero. States `s0` through
`s15` are the regulatory-unit probabilities `P(TL,TC,TR,CC)`, ordered by
`8*TL + 4*TC + 2*TR + CC`; `s16` through `s19` are
`mu_P^0,mu_P^1,mu_N^0,mu_N^1`. The committed CSV stores `step,Ta,s0,...,s19`
at update indices `0,30,99,157,299,599`, where index `N` is the result of the
update starting at `t=N ms`.

No ready-to-run generator is included because reproducing the authors' C++
program depends on the local compiler, Eigen, Boost, and system configuration.
The trusted data remain in
`tests/unitTests/reference_data/active_stress_regazzoni_twitch.csv`.
