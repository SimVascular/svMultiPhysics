# svbenchmark

This is a work in progress harness for running benchmarks in SVMultiPhysics.

## install

The easiest way to install is to use pip:

``` bash
pip install benchmarks/svbenchmark
```

Because this package is expected to change, it may be better to install it in "editable" mode so that it uses a link instead of copying the current version into your pipenv

``` bash
pip install -e benchmarks/svbenchmark
```
