24/**
25 * @brief Abstract active stress class.
26 *
27 * ## Table of contents
28 *
29 * - @ref activestress-overview
30 * - @ref activestress-inputs
31 * - @ref activestress-directions
32 * - @ref activestress-implementing
33 * - @ref activestress-coupling
34 *
35 * ## Overview {#activestress-overview}
36 *
37 * This class provides an interface for defining active stress models, i.e.
38 * models that, in the context of structural mechanics of muscular tissue,
39 * compute an active tension representing the contribution of muscular
40 * contraction to the constitiutive law.
41 *
42 * The class assumes that the active tension can be expressed as
43 * @f[
44 * \Tact = \Tact(t, \calcium, \fiberstretch, \fiberstretchrate,
45 * \astressstate),
46 * @f]
47 * where @f$\calcium@f$ is the intracellular calcium concentration,
48 * @f$\fiberstretch@f$ is the fiber stretch, @f$\fiberstretchrate@f$ is the
49 * fiber stretch rate, and @f$\astressstate@f$ is a vector of internal state
50 * variables, representing the state of contraction.
51 *
52 * The expression assumed above implies that the active tension is a local
53 * function of the variables it depends on, that is the active tension at a
54 * given point only depends on the value of other variables at that same point.
55 * Accordingly, this class works nodally, storing the state of contraction at
56 * every mesh node and evaluating the active tension from it, on demand,
57 * through @ref ActiveStress::compute_tension.
58 *
59 * ## Preprocessing of model inputs {#activestress-inputs}
60 *
61 * Two parameters, set at the top level of the @c <Active_stress> XML element
62 * and shared by all models, modify the inputs before they reach the model:
63 *
64 * - @c Calcium_scaling_factor (default @c 1.0): calcium is multiplied by this
65 * factor, e.g. to convert between the units of the electrophysiology model
66 * and those expected by the active stress model.
67 * - @c Disable_force_strain_rate_feedback (default @c false): if @c true, the
68 * fiber stretch rate is set to zero, and its computation is skipped.
69 *
70 * Both are applied once, in @ref update, so that @ref advance_time_step_local
71 * receives already scaled calcium and an already zeroed stretch rate. Models
72 * that do not use calcium or the stretch rate ignore them.
73 *
74 * ## Directional distribution of active stress {#activestress-directions}
75 *
76 * In muscular mechanics models, active stress normally acts only along the
77 * direction of fibers @f$\fiberdirection@f$, reflecting the fact that
78 * contractile units are aligned with fibers. However, one might want to account
79 * for fiber dispersion, i.e. the fact that fibers are not perfectly and
80 * regularly aligned, but rather have a certain distribution of orientations
81 * centered around the principal direction @f$\fiberdirection@f$.
82 *
83 * This can be surrogated by defining the active stress tensor as
84 * @f[
85 * S_\text{act} = \Tact \left(
86 * \eta_f \fiberdirection \otimes \fiberdirection +
87 * \eta_s \sheetdirection \otimes \sheetdirection +
88 * \eta_n \sheetnormaldirection \otimes \sheetnormaldirection
89 * \right),
90 * @f]
91 * where @f$\sheetdirection@f$ and @f$\sheetnormaldirection@f$ are the sheet and
92 * sheet-normal directions, respectively, and @f$\eta_f@f$, @f$\eta_s@f$, and
93 * @f$\eta_n@f$ are coefficients that define the distribution the active tension
94 * along the three principal directions. The coefficients must be such that
95 * @f$\eta_f + \eta_s + \eta_n = 1@f$.
96 *
97 * This class stores the values of @f$\eta_f@f$, @f$\eta_s@f$ and @f$\eta_n@f$,
98 * and applies them in @ref ActiveStress::compute_tension, which returns
99 * @f$\eta_f \Tact@f$, @f$\eta_s \Tact@f$ and @f$\eta_n \Tact@f$, bundled in an
100 * @ref ActiveTension.
101 *
102 * ## Implementing concrete active stress models {#activestress-implementing}
103 *
104 * To implement a new active stress model, the following steps need to be taken:
105 *
106 * 1. Create a new class derived from @ref ActiveStress.
107 * 2. Override the methods @ref init_local, @ref advance_time_step_local,
108 * @ref compute_active_tension_local and
109 * @ref compute_active_tension_derivative_local, defining the initial
110 * condition, time evolution, active tension and its partial derivative with
111 * respect to the fiber stretch, respectively, for a single node.
112 * 3. Create a new class derived from @ref ActiveStressModelParameters to store
113 * the parameters specific to the new active stress model.
114 * 4. Override the methods @ref get_parameters,
115 * @ref read_model_specific_parameters and
116 * @ref distribute_model_specific_parameters to manage the parameters of the
117 * new active stress model.
118 * 5. Register the new class into the active stress model factory by using the
119 * macro @ref REGISTER_ACTIVE_STRESS_MODEL. The macro should be called in a
120 * `.cpp` file, not in a header file.
121 *
122 * Notice that if the model is expressed in terms of a system of ODEs, it can
123 * be implemented by deriving from @ref ActiveStressODE, which already addresses
124 * some of the points above.
125 *
126 * Models need no code of their own for calcium scaling or for disabling the
127 * force-strain-rate feedback, as these are applied by this class (see
128 * @ref activestress-inputs).
129 *
130 * ## Coupling with the structural mechanics problem {#activestress-coupling}
131 *
132 * The active tension depends on the fiber stretch @f$\fiberstretch@f$ both
133 * directly, through the expression of @f$\Tact@f$, and indirectly, through the
134 * state @f$\astressstate@f$, which is itself driven by the fiber stretch. The
135 * mechanics problem, in turn, depends on @f$\Tact@f$.
136 *
137 * Explicit time discretization for the direct dependence was observed to lead
138 * to instabilities. Accordingly, the direct dependence is discretized
139 * implicitly, that is the active tension is recomputed within the nonlinear
140 * iterations for the structure problem that uses ActiveStress. To facilitate
141 * the convergence of nonlinear iterations, this class also allows to compute
142 * the derivative @f$\frac{\partial\Tact}{\partial\fiberstretch}@f$, which is
143 * used to assemble tangent terms associated to this in the structural system.
144 *
145 * Indirect dependence was not observed to give rise to instabilities.
146 * Accordingly, it is discretized explicitly by default, meaning that the state
147 * is updated once per time step evaluating the fiber stretch
148 * @f$\fiberstretch@f$ using the displacement from the previous time step. The
149 * user can change this behavior by setting the parameter @c
150 * Implicit_state_coupling to @c true in the XML file. This will make the state
151 * update every nonlinear iteration. No tangent terms are computed for this
152 * contribution, so nonlinear iterations can be expected to converge more slowly
153 * when this is enabled.
154 */
155class ActiveStress {
156public:
157 /**
158 * @brief Active tension information at a point.
159 *
160 * This struct bundles the active tension along the three principal
161 * directions (fibers @f$\fiberdirection@f$, sheets @f$\sheetdirection@f$ and
162 * sheet normals @f$\sheetnormaldirection@f$) and their partial derivatives
163 * with respect to the fiber stretch.
164 *
165 * It is a convenience data structure used to pass this information to
166 * functions that consume active tension information (e.g. the structural
167 * mechanics assembly functions).
168 */
169 struct ActiveTension {
170 /// Tension along the fiber direction, @f$\eta_f \Tact@f$.
171 double fibers = 0.0;
172
173 /// Tension along the sheet direction, @f$\eta_s \Tact@f$.
174 double sheets = 0.0;
175
176 /// Tension along the sheet-normal direction, @f$\eta_n \Tact@f$.
177 double sheet_normals = 0.0;
178
179 /// Derivative of @ref fibers with respect to the fiber stretch, at fixed
180 /// state, @f$\eta_f \pdv*{\Tact}{\fiberstretch}@f$.
181 double d_fibers = 0.0;
182
183 /// Derivative of @ref sheets with respect to the fiber stretch, at fixed
184 /// state, @f$\eta_s \pdv*{\Tact}{\fiberstretch}@f$.
185 double d_sheets = 0.0;
186
187 /// Derivative of @ref sheet_normals with respect to the fiber stretch, at
188 /// fixed state, @f$\eta_n \pdv*{\Tact}{\fiberstretch}@f$.
189 double d_sheet_normals = 0.0;
190 };

192 /**
193 * @brief Helper to evaluate active tension at quadrature points.
194 *
195 * The active stress model stores the state at the degrees of freedom, but the
196 * active tension needs to be evaluated at quadrature points. This class
197 * allows to do that by interpolating the state to quadrature points and then
198 * evaluating the active tension there.
199 */
200 class Evaluator {
201 public:
202 /**
203 * @brief Update the evaluator for a given element.
204 *
205 * @param[in] active_stress Active stress model of the domain the element
206 * belongs to.
207 * @param[in] nodes Indices of the mesh nodes of the element.
208 */
209 void update(const ActiveStress &active_stress, const Vector<int> &nodes);
210
211 /**
212 * @brief Reset this evaluator so that @ref evaluate returns zero tension,
213 * until the next call to @ref update.
214 *
215 * Used for elements whose domain has no active stress model.
216 */
217 void clear() { active_stress_ = nullptr; }
218
219 /**
220 * @brief Compute the active tension at a quadrature point.
221 *
222 * @param[in] N Shape functions at the quadrature point, of the same nodes
223 * the state was gathered at by @ref update.
224 * @param[in] F Deformation gradient at the quadrature point.
225 * @param[in] fibers Fiber directions of the element, one per column, the first
226 * column being the fiber direction itself.
227 *
228 * @return Active tension along fibers, sheets and sheet normals, and their
229 * derivatives with respect to the fiber stretch, bundled in an object of
230 * type @ref ActiveTension.
231 *
232 * @tparam nsd Number of spatial dimensions.
233 */
234 template <int nsd>
235 ActiveTension
236 evaluate(const Eigen::Ref<const Eigen::VectorXd> &N,
237 const mat_fun::Matrix<nsd> &F,
238 const Eigen::Ref<const Eigen::Matrix<double, nsd, Eigen::Dynamic>>
239 &fibers) const;
240
241 private:
242 /// Active stress model of the domain the element belongs to, or null if
243 /// @ref clear was called last, or if this evaluator was never updated.
244 const ActiveStress *active_stress_ = nullptr;
245
246 /// State variables at the element nodes, of size (n_states, element
247 /// nodes).
248 Eigen::MatrixXd state_;
249
250 /// State variables interpolated at the quadrature point, of size
251 /// n_states. Scratch storage for @ref evaluate, mutable so that it can
252 /// stay const.
253 mutable Vector<double> interpolated_state;
254 };

256 /// Grants @ref Evaluator direct access to @ref states.
257 friend class Evaluator;

305 /**
306 * @brief Compute the active tension given the state vector and fiber stretch.
307 *
308 * @param[in] state State vector at the point.
309 * @param[in] fiber_stretch Fiber stretch at the point.
310 *
311 * @return Active tension along fibers, sheets and sheet normals, and their
312 * derivatives with respect to the fiber stretch, bundled in an object of
313 * type @ref ActiveTension.
314 */
315 ActiveTension compute_tension(const Vector<double> &state,
316 const double fiber_stretch) const {
317 const double tension = compute_active_tension_local(state, fiber_stretch);
318 const double derivative =
319 compute_active_tension_derivative_local(state, fiber_stretch);
320
321 return {eta_f * tension, eta_s * tension, eta_n * tension,
322 eta_f * derivative, eta_s * derivative, eta_n * derivative};
323 }
