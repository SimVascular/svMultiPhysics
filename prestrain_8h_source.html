17/// @brief Prestrain of a body imaged while subject to a load.
18///
19/// The mesh is the imaged geometry, which is subject to a load. The prestrain
20/// is a deformation gradient @f$ F_0 @f$ at every Gauss point that maps an
21/// unknown stress-free configuration to the mesh. A displacement @f$ u @f$
22/// from the mesh then gives the deformation gradient from the stress-free
23/// configuration by the multiplicative decomposition
24/// @f[
25/// F = (I + \nabla u) \, F_0,
26/// @f]
27/// with @f$ \nabla @f$ the gradient on the mesh.
28///
29/// The prestrain is used in a structural simulation to pull the integrals of
30/// the weak form back to the stress-free configuration. The solid kernels
31/// (struct_ns::struct_2d and struct_3d) transform
32/// - the shape function gradients, @f$ \nabla N \to \nabla_0 N = F_0^T \nabla N @f$,
33/// - the volume element, @f$ dV \to dV / \det F_0 @f$,
34/// - every fiber direction, @f$ f \to f_0 = F_0^{-1} f / |F_0^{-1} f| @f$.
35///
36/// The solid kernels then keep their total Lagrangian form, with the
37/// deformation gradient above, computed from the displacement on the mesh as
38/// @f$ F = (I + \sum_a u_a \otimes \nabla N_a) \, F_0 @f$.
39///
40/// A fiber is a material line, so @f$ F_0^{-1} @f$ carries it from the mesh to
41/// the stress-free configuration and changes its length by the stretch the
42/// prestrain gives it. The material laws expect a unit direction in their
43/// reference configuration and measure the fiber stretch as @f$ |F f_0| @f$,
44/// so the pulled-back vector is normalized; at @f$ u = 0 @f$ that stretch is
45/// then the fiber's prestretch, @f$ 1 / |F_0^{-1} f| @f$. Every fiber is pulled
46/// back on its own, so a basis orthonormal on the mesh is orthonormal in the
47/// imaged configuration, not in the stress-free one.
48///
49/// The formulation is objective: rotating the deformed body rigidly rotates
50/// @f$ F @f$ and the internal forces with it.
51///
52/// @f$ F_0 @f$ is found by Newton's method on the imaged geometry. Every
53/// Newton iteration starts from rest under the full load, so its residual is
54/// that of the current @f$ F_0 @f$. The displacement @f$ u @f$ it reaches is
55/// composed into the prestrain,
56/// @f[
57/// F_0 \leftarrow (I + \nabla u) \, F_0,
58/// @f]
59/// and discarded. At the fixed point the mesh carries the load in Cauchy
60/// stress equilibrium without moving. This is the incremental scheme of
61/// [Gee, Forster and Wall (2010)](https://doi.org/10.1002/cnm.1236), section
62/// 3, with the increments composed on the imaged mesh, so that equilibrium
63/// holds on the imaged geometry rather than on a virtually deformed one.
64/// Because each iteration is composed, the tangent of the composed residual
65/// differs from the kernel's own, and the solid kernels correct it (see
66/// struct_ns::prestrain_tangent_correction). Max_iterations and Tolerance
67/// bound the iterations of a time step as in any other run. The residual force of every
68/// step is written to prestrain_residual.csv in the results folder, and with
69/// Adaptive_time_step the time step is adapted to
70/// the residual between steps (see Integrator.h).
71///
72/// Each mesh holds @f$ F_0 @f$ in a Prestrain, one tensor per Gauss point,
73/// written to and read from VTU cell arrays named Prestrain_F_g<g>, one per
74/// Gauss point.
75///
76class Prestrain {
77public:
78 /**
79 * @brief Reads the prestrain from the Prestrain_F_g<g> cell arrays of the
80 * VTU file named by Prestrain_file_path, in the mesh's original element
81 * order.
82 */
83 void read(const MeshParameters& mesh_parameters, const mshType& mesh, int nsd);
84
85 /**
86 * @brief Parallel distribution of the prestrain according to the mesh's
87 * element partition.
88 */
89 void distribute(const CmMod& cm_mod, const cmType& cm, const mshType& mesh);
90
91 /**
92 * @brief Returns true if the mesh carries a prestrain. The same on every
93 * rank once distributed, also on a rank that holds none of the mesh's
94 * elements.
95 */
96 bool has_prestrain() const { return F0.nrows() != 0; }
97
98 /**
99 * @brief Sets the prestrain to the identity at every Gauss point.
100 */
101 void set_identity(int nsd, int nG, int nEl);
102
103 /**
104 * @brief Returns the prestrain at Gauss point g of element e, nsd x nsd.
105 * The mesh must carry a prestrain (see has_prestrain).
106 */
107 Eigen::MatrixXd get(int g, int e) const;
108
109 /**
110 * @brief Returns the element average of the prestrain, for output whose
111 * quadrature differs from the mesh's. The mesh must carry a prestrain.
112 */
113 Eigen::MatrixXd get_mean(int e) const;
114
115 /**
116 * @brief Gathers the prestrain onto the master in the mesh's original
117 * element order, for writing, and returns it there: one row per component
118 * and Gauss point, one column per element. Empty on the other ranks.
119 * Collective: every rank must call it, also a rank that holds none of the
120 * mesh's elements.
121 */
122 Array<double> gather(const ComMod& com_mod, const CmMod& cm_mod, const mshType& mesh) const;
123
124 /**
125 * @brief F0 <- (I + Grad u) F0 at every Gauss point of the mesh, with u a
126 * nodal displacement field on the mesh, nsd x tnNo.
127 */
128 void compose(const ComMod& com_mod, const mshType& mesh, const Array<double>& u);
129
130private:
131 /**
132 * @brief Prestrain at the quadrature points.
133 *
134 * Indexed as @c (component, gauss_point, element):
135 * - @c component packs the nsd x nsd tensor in the column-major order of
136 * Matrix<nsd>, @f$ i + j \cdot n_{sd} @f$ for row @f$ i @f$ and column
137 * @f$ j @f$;
138 * - @c element is the local element index after @ref distribute (or the
139 * global element index before it).
140 */
141 Array3<double> F0;
142
143 /// Number of spatial dimensions of the prestrain tensors.
144 int nsd = 0;
145
146 /// The tensor of Gauss point g of element e, ready only.
147 const double* block(const int g, const int e) const
148 {
149 return F0.data() + (static_cast<size_t>(e) * F0.ncols() + g) * F0.nrows();
150 }
151 // The tensor of Gauss point g of element 3, writable.
152 double* block(const int g, const int e)
153 {
154 return F0.data() + (static_cast<size_t>(e) * F0.ncols() + g) * F0.nrows();
155 }
156};
