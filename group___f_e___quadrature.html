Detailed Description

Integration rules on canonical reference cells.

A QuadratureRule owns ordered reference coordinates and weights for

\[ \int_{\hat K} f(\hat x)\,d\hat x \approx \sum_q w_q f(\hat x_q). \]

Supported families use these canonical reference cells:

Family Reference cell Measure
Point \((0,0,0)\) \(1\)
Line \([-1,1]\) \(2\)
Triangle \(\{(x,y):x,y\geq0,\ x+y\leq1\}\) \(1/2\)
Quad \([-1,1]^2\) \(4\)
Tetra \(\{(x,y,z):x,y,z\geq0,\ x+y+z\leq1\}\) \(1/6\)
Hex \([-1,1]^3\) \(8\)
Wedge unit triangle \(\times[-1,1]\) \(1\)

The family therefore determines both reference dimension and cell measure. Quadrature points are not required to lie inside the reference cell. Generating code is responsible for verifying weight normalization and declared polynomial exactness through analytic moment tests.

QuadratureRule svmp::FE::quadrature::make_gauss_legendre_rule ( int  requested_exactness)

Generate a Gauss-Legendre rule on \([-1,1]\) with at least the requested exactness.

For \(d\) = requested_exactness, integer division gives the minimum point count \(n=\lfloor d/2\rfloor+1\). The returned metadata reports the actual polynomial exactness \(2n-1\), which exceeds even requests by one. Degree zero produces one point with exactness one. Points are the roots of the Legendre polynomial \(P_n\) of degree \(n\), in strictly increasing order inside \((-1,1)\); neither endpoint is included. Weights are positive and aligned with their points.

See also
NIST DLMF: Legendre polynomials
Parameters
requested_exactnessMinimum polynomial degree to integrate exactly; must be in [0, 255], inclusive (see max_gauss_legendre_exactness()).

A complete QuadratureRule value for CellFamily::Line.
Exceptions

QuadratureRule svmp::FE::quadrature::make_gauss_lobatto_rule ( int  requested_exactness)

Generate a Gauss-Lobatto-Legendre rule on \([-1,1]\) with at least the requested exactness.

For \(d\) = requested_exactness, integer division gives the minimum point count \(n=\lfloor d/2\rfloor+2\). The returned metadata reports the actual polynomial exactness \(2n-3\), which exceeds even requests by one. Degree zero produces two points with exactness one. The first and last points are exactly \(-1\) and \(+1\). When present, the \(n-2\) interior points are the roots of \(P'_{n-1}\), the derivative of the Legendre polynomial of degree \(n-1\). Points are strictly increasing, and weights are positive and aligned with their points.

See also
NIST DLMF: Legendre polynomials
