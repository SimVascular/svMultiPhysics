10/// @brief Add the contribution of the coupled Neumann faces to a
11/// matrix-vector product.
12///
13/// A coupled face contributes the operator
14///
15/// coef * scaled_unit_pressure_load * scaled_flowrate_derivative^T
16///
17/// where coef is face.res when adding the contribution to the product, and
18/// -face.res / (1 + face.res * face.nS) when computing the contribution to
19/// the preconditioner.
20///
21/// For reference, see
22/// Moghadam et al. 2013 eq. 27 (https://doi.org/10.1016/j.jcp.2012.07.035) and
23/// Moghadam et al. 2013b (https://doi.org/10.1007/s00466-013-0868-1).
24///
25/// @param[in] lhs The left-hand side of the linear system, whose faces are
26/// read.
27/// @param[in] op_Type Whether to compute the contribution to the product or
28/// to the preconditioner.
29/// @param[in] X The vector that the operator is applied to (components per
30/// node x lhs.nNo).
31/// @param[in,out] Y The vector that the result is added to, of the same size
32/// as 'X'.
33void add_bc_mul(const FSILS_lhsType& lhs, const BcopType op_Type, const Array<double>& X, Array<double>& Y);
34
35/// @brief Compute the squared norm of the scaled unit pressure load of each
36/// coupled Neumann face.
37///
38/// The result is stored in face.nS, which add_bc_mul() reads for the
39/// contribution to the preconditioner. Every process has to make this call.
40///
41/// @param[in,out] lhs The left-hand side of the linear system. Only the nS of
42/// its coupled faces is modified.
43/// @param[in] num_components The number of components per node that enter the
44/// norm, starting from the first.
45void compute_coupled_face_norms(FSILS_lhsType& lhs, const int num_components);
