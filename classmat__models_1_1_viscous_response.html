Detailed Description

template<int nsd>
class mat_models::ViscousResponse< nsd >

Viscous 2nd Piola-Kirchhoff stress and tangent contributions at a Gauss point, for the viscosity model configured for the domain.

Owns the buffers it computes into, so a kernel can hold one instance across an element's Gauss points and skip the calls it does not need.

Evaluate the domain's viscosity model at this Gauss point.

Dispatches to the viscous pseudo-potential or Newtonian model, or zeroes the contributions when the domain has no viscosity model.

Does nothing when recompute is false, preserving values from the previous call. Used for linear triangules and tetrahedra for which Nx, vx, and F are constant across the element's Gauss points.
