Array< double > Fibers::get_quadrature_fibers ( int nsd,
int g,
int e,
bool orthonormalize = false ) const

Returns fibers at a quadrature point.

Raw directions are returned by default. When orthonormalize is true, an owned, completed orthonormal basis is returned without modifying or caching the raw fibers. Constant and cell directions are completed directly; interpolated point directions are first orthonormalized.
